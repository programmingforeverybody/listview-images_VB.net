# Load Images into ListView from Folder in VB.NET
### Step by Step – Visual Studio 2026 (With Source Code)

This project demonstrates how to **load images from a folder into a ListView control** in a **VB.NET Windows Forms application** using **Visual Studio 2026**.  
It is designed step by step and suitable for **beginners and intermediate developers**.

---

## 🚀 Features
- Load all image files from a selected folder
- Display images inside a **ListView**
- Use **ImageList** for efficient image handling
- Support common image formats (JPG, PNG, BMP, GIF)
- Clean and easy-to-understand VB.NET code
- Fully compatible with **Visual Studio 2026**

---

## 🛠 Technologies Used
- **VB.NET**
- **Windows Forms**
- **Visual Studio 2026**
- **.NET Framework / .NET (Desktop)**

---

## 📂 How It Works (Step by Step)

1. Select an image folder from your computer
2. Read all image files inside the folder
3. Add each image to an `ImageList`
4. Bind the `ImageList` to a `ListView`
5. Display images in LargeIcon or SmallIcon view
